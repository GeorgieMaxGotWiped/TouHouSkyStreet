How to Play

玩法

Controls · Systems · Display

一句话：躲弹幕、打 Boss、捡东西、变强，然后进下一面。下面是从键位到存档的全部规矩。

操作

键位

Controls
方向键移动自机。低速模式下移动速度减半，判定点会显形。
Z Space射击。长按持续开火。
Shift低速模式。用来在密集弹幕里走细线，也是部分装备效果的触发条件。
X炸弹。清屏并对 Boss 造成伤害，次数显示在 HUD 上。
C释放当前装备携带的 C 技能。每一面有使用次数限制，同时只能装备一件带 C 技能的物品。
Esc暂停。可继续、重开或退回主菜单。
F8 F9 F10减速 / 加速 / 恢复 1.0x，范围 0.25x 到 2.0x。
F11切换无边框全屏。

主菜单、设置、自机选择、出征准备、符卡练习、Boss 奖励与休整界面全部支持鼠标：悬停即切换选中项，左键点击直接确认；较长的物品列表可以用滚轮上下翻。

出征

自机与难度

Setup

主菜单 Start Game 之后是两步：先选自机，再选难度。

Step 1选择自机

  • 四位自机：魔法使 Mage、弓手 Archer、重装 Tank、冰焰 Frozen Blaze。
  • 选择只影响立绘、战斗形象与自机弹形状，判定点与炸弹规则完全一致。
  • 选中的自机一路带进关卡，剧情对话里的立绘与名牌也会跟着换。
  • 左右 / 上下 / 滚轮切换，Enter 或 Z 确定。

Step 2选择难度

  • 当前开放 Easy。
  • Normal / Hard / Lunatic 列在同一个界面里，显示为锁定状态。
  • 也可以在命令行直接指定：python main.py easy。
循环

一局的流程

Loop

本作不是「一路打到底」，每一面之间都会停下来让你整理装备。

  1. 道中

    小怪波次按时间轴推进，掉落 Power 方块、金币与物品。屏幕右侧的 HUD 实时显示残机、炸弹、Power、Graze 与 Combat 等级。

  2. 道中 Boss

    每面中段有一位道中 Boss，打到血量门槛才放符卡。击破后还有一小段小怪，清空才算过关。

  3. 关底 Boss

    非符阶段与符卡交替进行，最后一张通常是 Last Spell。开符时屏幕上会压出符卡名称的横幅。

  4. Boss 奖励

    击破后进入奖励界面挑选掉落。带 B 的撤离动作发生在休整阶段，奖励阶段拿的东西还不算落袋。

  5. 休整

    可以买卖物品、换装备、用重铸石给装备加前缀、查看背包与仓库。准备好就按 N 进下一面。

  6. 撤离或继续

    按 B 撤离，把这一局拿到的物资存进本地仓库；按 N 继续往上打——打输就什么都没了。

Ex 面（裂隙）是例外：不经仓库出征、不结算物品、不进休整与奖励界面，通关后直接回主菜单。

物品

物品、重铸与 C 技能

Items
一

稀有度

从 Common 到 Very Special 共九档，颜色沿用 SkyBlock 的配色。稀有度决定基础属性区间与掉落权重。

二

部位

武器、护甲与护符各占一个装备槽，同一件装备的不同重铸前缀会分别记录，互不混淆。

三

重铸石

在锻造页对装备使用重铸石，附加类似 Necrotic、Loving 这样的前缀，直接改写自机弹或炸弹的表现。

四

本地仓库

按 B 撤离后，本局物资进入本地仓库并跨局保留；主菜单的 Storage 入口可以随时查看仓库，并对仓库里的装备直接重铸。

画面

画面与显示

Display

设置界面里的四行，决定了游戏在你的屏幕上有多清楚。

输出分辨率1x / 2x / 3x / 4x，决定窗口与渲染目标的实际像素尺寸。
缩放模式整数倍（画面边缘不留余量，颗粒感最准）或填充（铺满窗口）。
渲染倍率1x / 2x / 3x。地面、弹幕、敌机、Boss、自机、立绘与文字都按这个倍率原生绘制，放大只增加细节。
Boss 立绘在「新版」与「另一版」两套 Boss 立绘之间即时切换。
游戏速度0.25x 到 2.0x 的调节条，等价于战斗中的 F8 / F9 / F10。

以上选择都会写进游戏目录下的 config.json，下次启动沿用。

练习

打不过的时候

Practice

主菜单的 Practice 可以单独练一张符卡，不用从头把整面再打一遍。

Practice符卡练习

  • 左列选 Boss，右列选符卡，包括各面的 Last Spell。
  • 练习舞台复用真实关卡的背景与符卡演出，手感与正篇一致。
  • 进入前会先经过载入界面预载该 Boss 的贴图，避免开打才卡一下。

Extra StageEx 面

  • 主菜单直接进，不需要经过仓库与装备准备。
  • 道中 Boss Wizardman、关底 Boss Barry，两张都是非符弹幕支撑的硬仗。
  • 通关后不结算物品，直接回主菜单。
