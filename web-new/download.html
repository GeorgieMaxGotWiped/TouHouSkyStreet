下载与运行

Windows 10 / 11

两条路：拿打包版直接双击，或者用源码跑。两条路都在 Windows 10 / 11 上验证过。

Route A打包版（免 Python）

  • 解压后得到 TouHouSkyStreet 文件夹，双击里面的 TouHouSkyStreet.exe 即可开打。
  • 不需要装 Python，也不需要联网。
  • 是 64 位产物，系统必须是 64 位 Windows 10 / 11。
  • 资源约 470 MB，所以用文件夹版而不是单文件版——就地读资源，启动快，素材还能随时替换。

Route B源码运行

  • 需要 Python 3.8 以上，安装时记得勾选 Add Python to PATH。
  • 双击根目录的 启动游戏.bat，它会自动检测并安装缺失的依赖。
  • 或者手动来：pip install -r requirements.txt 之后 python main.py。
  • 想在命令行直接指定难度：python main.py easy。
前往 ReleasesGitHub 浏览源码仓库GitHub

如果 Releases 里还没有打包产物，可以直接克隆仓库用源码运行，或者按仓库里的说明自行打包。

第一次启动

First Run

  1. 让它自己检查依赖

    源码版第一次运行 启动游戏.bat 时，脚本会找本机的 Python 并安装缺的包，装完自动进游戏。

  2. 在主菜单按下第一项

    上下键移动光标，Enter 或 Z 确认。Start Game 之后是选自机、再选难度。

  3. 先把画面对清楚

    进设置把输出分辨率、缩放模式与渲染倍率调到你满意，再开打。这些值会存进 config.json。

  4. 打不过就进 Practice

    符卡练习可以单独练任意一张符卡，不用从头再打一遍整面。

存档

设置与仓库放在哪

Save Data

config.json用户设置

  • 音量、游戏速度、Boss 立绘版本、输出分辨率、缩放模式、全屏、默认自机与渲染倍率。
  • 与游戏程序放在同一目录。

warehouse.json本地仓库

  • 撤离时存进来的物资，跨局保留。
  • 同样与游戏程序同目录；重装或换机器时，把这个文件一起带走就不会丢东西。
排查

找不到 Python 怎么办

Troubleshooting
  • 在项目根目录新建一个 python_path.txt，第一行写上 Python 可执行文件的完整路径，例如 C:\Python313\python.exe。
  • 启动脚本会优先读这个文件，找不到就退回直接用 python。
  • 仍然起不来时，在命令行手动执行 python main.py，把报错信息留下来便于定位。
  • 部分音乐文件还在打磨中，缺失或播放失败会被自动跳过，不影响运行。
