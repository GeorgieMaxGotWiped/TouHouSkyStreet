关于本作

A Touhou Fan Game

東方天空街是一个人的同人企划：把 Hypixel SkyBlock 的收集成长，塞进东方弹幕射击的骨架里。不收费，不商用，做出来是因为想玩。

是什么

一句话说清楚

What It Is

这是一款纵向卷轴弹幕射击游戏，四位自机、六面正篇加一面 Ex，35 张符卡与十七位 Boss。
但它的骨架不只是弹幕：每一面之间会停下来让你买卖、装备与重铸，打完想保住战利品就得主动撤离。收集与风险，是弹幕之外的第二层玩法。

怎么做的

技术栈

Tech
一

Python + Pygame

引擎、实体、关卡、UI 全部自写，没有用现成的 STG 框架。逻辑与绘制都跑在自己的循环里。

二

原生分辨率渲染

地面、弹幕、敌机、立绘与文字按渲染倍率直接由显卡绘制，而不是把 1x 画布整体放大，所以高分屏上放大只增加细节。

三

伪 3D 走廊

洞穴地面与洞壁由显卡按行与列逐条绘制并左右镜像，做出可以走的走廊纵深，而不是贴一张背景图。

四

数据驱动的关卡

自机、符卡、物品、Boss 立绘都登记在配置表里，加一位自机或改一张符卡不需要动渲染代码。

About This Site

整站没有用任何框架与第三方库：纯静态 HTML / CSS / JavaScript，字体、立绘、关卡标题卡与实机截图全部直接取自游戏仓库，由 tools/build_assets.py 转成 WebP 后发布。
背景那层弹幕是一个手写的 canvas 小引擎——环形、螺旋与自机狙扇形三种发射器，颜色取自游戏本体的调色板。
