Gameplay

玩法介绍

弹幕射击为骨，Skyblock 收集成长为肉。

核心玩法

本作是一款基于 Hypixel Skyblock 的东方 Project 同人弹幕射击游戏（STG）。你需要在 6 个舞台中躲避密集弹幕、击破道中与 Boss，收集并养成装备，最终抵达天空街的尽头。

战斗

  • 密集弹幕射击，配合擦弹与雷（Bomb）保命。
  • Boss 拥有多张符卡，战至血条尽头进入下一阶段。
  • 击破符卡后可获得物品掉落与奖励。

收集与养成

  • 54+ 件可掉落物品：武器 / 护甲 / 护符 / 重铸石 / 材料。
  • 掉落概率遵循 items.md 表格；爆率加成按乘算，其余 +xx% 效果按加算。
  • 部分物品携带 C 技能（C 键释放，每面限次，同时只能装备 1 件）。
  • 重铸石可为装备附加前缀，构筑个性化强度。

休整与仓库

  • 每关之间进入休整阶段，可购买 / 出售物品。
  • 按 B 键撤离，将本局物资存入本地仓库。
  • Game Over 时本局装备与金币不会保留。

操作方式

动作按键 / 操作
移动方向键 / WASD
射击Z（按住）
集中（低速）Shift
雷（Bomb）X
C 技能C
菜单 / 关卡方向键 + 鼠标点击
对话推进回车 / 鼠标左键

鼠标支持

主菜单 / 设置 / 出征准备 / 符卡练习 / Boss 奖励 / 休整界面均支持鼠标：悬停切换、左键确认。休整界面底部按钮与页签、装备槽、背包、商店、锻造均可点击，较长列表支持滚轮滚动。

难度与模式

  • 难度：Easy / Normal / Hard / Lunatic，可在启动参数中指定。
  • 练习模式：主菜单选择 Practice，可选 Boss 与符卡（含 Last Spell）；固定满火力（400）、3 残机、3 雷；击破后可按 R 重试、N 下一张、Esc 返回。
  • 练习模式不写入主线存档。

运行方式

  • 双击 启动游戏.bat（自动检测 Python 环境）。
  • 或命令行：python main.py。
  • 指定难度：python main.py normal。
