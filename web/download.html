下载版

游戏打包为 TouHouSkyStreet 文件夹（TouHouSkyStreet.exe 与 _internal），解压后双击里面的 exe 即可运行，无需安装 Python。压缩包将随 GitHub Releases 发布。

请解压到桌面或任意可写目录再运行：程序需要在同目录写入 config.json 设置与 warehouse.json 仓库存档，所以不要放在 C:\Program Files 这类受保护目录下。

打包命令等价于：pip install -r requirements-build.txt 后执行 python -m PyInstaller --onedir --noupx --name TouHouSkyStreet --add-data "assets;assets" --noconsole main.py。

源码运行

若希望从源码运行，请确保本机已安装 Python 3.8+（安装时勾选 “Add Python to PATH”）。

  1. 双击根目录 启动游戏.bat（自动检测 Python 与依赖），或手动执行 pip install -r requirements.txt。
  2. 命令行运行：python main.py。
  3. 指定难度：python main.py easy|normal|hard|lunatic。

若自动检测仍找不到 Python，可在根目录新建 python_path.txt，第一行填写 Python 可执行文件完整路径（如 C:\Python313\python.exe）。
