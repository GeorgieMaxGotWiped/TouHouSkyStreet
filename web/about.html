项目简介

东方天空街 ~ Touhou Sky Street 是一款基于 Hypixel Skyblock 的东方 Project 同人弹幕射击游戏（STG），使用 Python + Pygame 开发。玩家在 6 个舞台中躲避密集弹幕、击破道中与 Boss，收集并养成 Skyblock 风格物品。

技术栈

  • 游戏：Python 3.8+ / Pygame，支持打包为单文件 Windows EXE。
  • 网站：纯静态 HTML / CSS / JavaScript，零构建依赖，便于托管到任意静态空间。
